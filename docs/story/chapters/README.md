# Chapters

One file per chapter, named `ch<N>-<slug>.md`, written once the story arc is
outlined (STY-2). Template:

```markdown
# Chapter N: <Title>

## Summary
Two or three sentences.

## Beats
1. Where, who, what happens, what the player does. Flags set.
2. ...

## Locations
| Map id | Kind | Purpose | New or existing |

## Characters
Who is in the party, who joins or leaves, named NPCs.

## Content notes
- Target level at start and end:
- Expected gear:
- Encounter groups per area:
- Treasure list (chest id, contents):
- Shops and prices:
- Boss:
```
