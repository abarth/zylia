# Story

This folder holds the framework for writing Zylia's story. **No story has
been written yet**, on purpose. The story is the heart of an FF4/FF6-style
game, so it is designed in deliberate stages, with competing drafts,
critique against explicit principles, and the project owner's approval
before each stage builds on the last.

## Layout

| Path | What it holds |
| --- | --- |
| [principles.md](principles.md) | What we mean by a compelling story; the craft rules every draft is held to |
| [process.md](process.md) | The stages, from premise to dialogue, and how drafts become canon |
| [review.md](review.md) | The critique rubric and how reviews are run |
| [style-guide.md](style-guide.md) | Voice, tone, naming and text-box constraints for all written text |
| [templates/](templates/) | One template per kind of story document |
| [drafts/](drafts/README.md) | Work in progress: pitches and drafts under review. Not canon. |
| [canon/](canon/README.md) | Approved story. The only source content may be built from. |

## Rules

1. **Only `canon/` is true.** Content (maps, NPCs, dialogue) may only use
   facts that are in `canon/`. Drafts are ideas, however good.
2. **Top-down.** Each stage builds on approved canon from the previous
   stage. See [process.md](process.md).
3. **Compete, critique, choose.** Important decisions (premise, cast, arc)
   start with several distinct drafts, each reviewed against
   [review.md](review.md), and the owner chooses.
4. **Track promises.** Every setup, mystery and foreshadowing goes in
   [canon/threads.md](canon/threads.md) with its planned payoff.
5. **Changing canon is allowed, and is explicit.** A change to approved canon
   says what it changes downstream and gets the owner's approval like any
   other stage.

## Placeholder content

The content currently in the game (the town of Aldren, the Mossy Cave, Elder
Bram, Kael and Mira) exists only to exercise the engine. None of it is canon
and none of it constrains the story.
