# Story Bible

This folder is the single source of truth for Zylia's world, characters and
plot. All dialogue and content must agree with it. Everything here is
written by agents and reviewed by the project owner.

## Documents

| Doc | Contents | Status |
| --- | --- | --- |
| [world.md](world.md) | Setting, geography, history, factions, magic in the fiction | Seed ideas |
| [characters.md](characters.md) | Playable cast and major NPCs, with the design template | Template + seed concepts |
| [story-arc.md](story-arc.md) | The overall plot structure and each character's arc through it | Proposed structure |
| [style-guide.md](style-guide.md) | Tone, naming, dialogue voice, text limits | Draft |
| [chapters/](chapters/README.md) | One beat sheet per chapter, plus its content notes | Not started |

## Process

Story is designed top-down, then refined bottom-up as content is built:

1. **World and premise** (world.md): what the world is and what is wrong
   with it.
2. **Cast** (characters.md): who the playable characters are, what each
   wants, and what they must face.
3. **Arc** (story-arc.md): the acts and turning points of the main plot,
   and where each character's personal plot peaks.
4. **Chapters** (chapters/): beat sheets that turn the arc into scenes in
   places, with the content each needs.
5. **Content** (`content/`): maps, NPCs, dialogue built from the chapter
   docs (see [../content/authoring-guide.md](../content/authoring-guide.md)).

When a lower layer needs to change a higher one (a scene needs a new
backstory detail), update the higher document in the same change.
